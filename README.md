# Enterprise IT Asset Lifecycle & Risk Dashboard

## Problem
Organizations often track IT assets across multiple disconnected systems (IT inventory vs. finance records), leading to data discrepancies, unmanaged or "ghost" devices, missed audits, and security blind spots from outdated software.

## Approach
This project simulates that environment using a synthetic dataset of 500 IT assets. It uses SQL and Python to reconcile records between two systems, identify risks, and visualize findings in an interactive dashboard.

## Tools
Python (pandas, Faker), SQL (SQLite), Power BI, PowerShell
